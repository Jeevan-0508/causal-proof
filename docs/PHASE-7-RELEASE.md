# Phase 7 Release Notes

Phase 7 adds the graph studio, forensic timeline explorer, multi-hypothesis
comparison, guided synthetic walkthrough, graph revision history, stale-parent
protection, stronger evidence hash validation, and server-side replay/branch
binding checks.

Validation includes the existing Phase 1–6 suite plus Phase 7 graph-cycle,
duplicate-identity, timeline-cutoff, hypothesis-comparison, graph-revision,
replay/branch integrity, Playwright workflow, typecheck, production build,
dependency audit, and repository secret scans.

The release remains local-first, synthetic-only, Apache-2.0, and not a legal,
regulatory, forensic-admissibility, or causal-certainty claim. No deployment or
npm publication is part of this phase.
