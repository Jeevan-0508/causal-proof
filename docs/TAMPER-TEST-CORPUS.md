# Tamper and adversarial corpus

The corpus covers changed payloads, recomputed manifests, cross-investigation IDs, reordered mutations, graph hash edits, replay hash edits, hindsight-set overlap, branch references without a replay, simulation input changes, fabricated copilot citations, invalid review references, missing sections, and secret-like fields. Expected results are rejection with a specific verification code; recomputing unkeyed hashes does not make semantically inconsistent data valid.

Prompt-injection text remains evidence content and is never an instruction. Copilot claims must cite package-authorized evidence. Unknown, revoked, missing, or rollback checkpoints are not upgraded to authenticity.
