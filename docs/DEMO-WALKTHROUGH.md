# Synthetic Demo Walkthrough

The Guided Demo is a functional checklist over the synthetic Northstar
investigation: discovery, evidence, chronology, contradiction, graph studio,
replay, simulation, copilot, review/integrity, and export. Buttons navigate to
the real workspaces or invoke the real deterministic action. It does not use
pre-recorded UI output and does not claim empirical metrics. Demo mode is
explicitly configured and rejected in production.
