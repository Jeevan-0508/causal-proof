# Accessibility Audit

Phase 7 preserves semantic form labels, keyboard-operable buttons, focus-visible
styles, reduced-motion CSS, responsive layouts, and a visible guided workflow.
The graph projection is supplemented by node and edge controls so the visual
graph is not the only interaction path.

Known limitations remain: the evidence drawer needs a full focus trap and
restoration strategy, the rail is not yet a formal tablist, and automated
testing does not establish WCAG conformance. These are Phase 8 hardening items.
