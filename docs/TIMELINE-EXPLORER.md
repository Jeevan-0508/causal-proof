# Timeline Explorer

The explorer retains separate occurrence, detection, ingestion, evidence
availability, investigator-knowledge, and evidence-mutation clocks. Search and
kind filters operate on derived rows. Selecting a decision cutoff uses the
replay knowledge boundary and removes later rows from the analysis set rather
than hiding them cosmetically. Evidence and mutation rows link back to the
provenance drawer.

The timeline is forensic chronology, not a causal proof mechanism. Clock
ordering and missing timestamps remain visible limitations.
